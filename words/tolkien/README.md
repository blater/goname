# Tolkien word set

`names.txt` is a curated one-word list of character and place names compiled from Tolkien
Gateway's character indexes for [The Hobbit](https://tolkiengateway.net/wiki/Category:Characters_in_The_Hobbit),
[The Lord of the Rings](https://tolkiengateway.net/wiki/Category:Characters_in_The_Lord_of_the_Rings),
[The Silmarillion](https://tolkiengateway.net/wiki/Category:Characters_in_The_Silmarillion),
and [The Children of Húrin](https://tolkiengateway.net/wiki/Category:Characters_in_The_Children_of_H%C3%BArin),
as well as the Tolkien Gateway [location index](https://tolkiengateway.net/wiki/Index:Locations).
Character entries use a single familiar name and omit unnamed groups and role-only entries. Place
entries are selected locations from *The Hobbit* and *The Lord of the Rings*. This is a broad
selection, not a complete index of every character, alias, location, or Tolkien work.
